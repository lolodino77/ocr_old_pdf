MODERNISATEUR DE LIVRES ANCIENS - VERSION PORTABLE POUR MAC
============================================================

Le programme lit le texte de vieux livres en PDF (OCR), le modernise (orthographe actuelle) avec Gemini,
et vous rend un document Word, PDF et Markdown.

Il vous faut : un Mac avec macOS 10.14 (Mojave) ou plus récent (Apple M1, M2… ou Intel), une connexion
Internet, et environ 2 Go de place libre. Sur macOS 10.14 et 10.15, seul le mode « API Gemini » marche
(voir plus bas) : le mode « navigateur » demande macOS 11 ou plus récent. Rien ne s'installe ailleurs sur le Mac : tout reste dans le dossier que vous allez extraire.
Aucun mot de passe d'administrateur n'est demandé.

PREMIÈRE FOIS
-------------
1. Double-cliquez sur le fichier .zip reçu : le Finder crée le dossier « ModernisateurLivresAnciens-Mac ».
   Déplacez-le dans votre dossier personnel (Finder : menu Aller > Départ), PAS dans iCloud Drive.
2. Dans ce dossier, double-cliquez sur « Ouvrir le Modernisateur ».
   La première fois, macOS affiche un avertissement, car le fichier vient d'Internet :
   - macOS récent : « Terminé » (ou « OK »), puis menu Pomme > Réglages Système > Confidentialité et
     sécurité, tout en bas : « Ouvrir quand même », puis confirmez ;
   - macOS plus ancien : clic droit (ou Ctrl + clic) sur le fichier > « Ouvrir », puis « Ouvrir ».
   Autre possibilité, sans avertissement : ouvrez le Terminal, tapez « sh » suivi d'un espace, glissez le
   fichier « Ouvrir le Modernisateur » dans la fenêtre du Terminal, puis appuyez sur Entrée.
   Si macOS dit que le fichier est « endommagé » et ne propose que « Placer dans la corbeille » (fréquent quand
   le .zip a été reçu par Telegram, WhatsApp ou une messagerie) : il n'est PAS endommagé, macOS le bloque
   seulement. Cliquez sur « Annuler », ouvrez le Terminal (Launchpad > Autre > Terminal), puis tapez
   « xattr -cr » suivi d'un espace, glissez le dossier « ModernisateurLivresAnciens-Mac » dans la fenêtre,
   appuyez sur Entrée ; ensuite, tapez « sh » suivi d'un espace, glissez le fichier « Ouvrir le Modernisateur »
   dans la fenêtre, appuyez sur Entrée. Pour éviter ce blocage, téléchargez plutôt le .zip depuis un lien
   (Google Drive, WeTransfer...) ou par e-mail.
3. Une fenêtre de Terminal prépare le programme (Python, Tesseract, langues, navigateur...). Comptez 5 à
   10 minutes, une seule fois. Ne la fermez pas. À la fin, le programme s'ouvre dans votre navigateur.

ENSUITE
-------
- Double-cliquez sur l'application « Modernisateur de livres anciens », créée dans le dossier
  (vous pouvez la glisser dans le Dock). Elle ouvre le programme sans fenêtre de Terminal.
- Le programme s'ouvre dans votre navigateur : déposez vos PDF, choisissez la langue, puis cliquez sur
  « Démarrer la modernisation ». Les documents produits se téléchargent depuis la page.
- Pour le fermer : bouton « Quitter le programme », dans la colonne de gauche de la page.

DEUX FAÇONS D'UTILISER GEMINI
-----------------------------
- « Navigateur (sans clé API) » : rien à configurer. Une fenêtre de navigateur s'ouvre pendant la
  modernisation : ne la fermez pas. (Google Chrome est utilisé s'il est installé.)
  Il demande macOS 11 ou plus récent.
- « API Gemini (clé requise) » : créez une clé gratuite sur https://aistudio.google.com/apikey et
  collez-la dans le champ prévu sur la page. Pour ne plus avoir à la saisir : copiez le fichier
  programme/.env.example en programme/.env, et remplacez « votre_cle_ici » par votre clé.

DÉPLACER LE DOSSIER
-------------------
Possible à tout moment (programme fermé). Ensuite, double-cliquez sur « Ouvrir le Modernisateur » : il se
répare tout seul en une ou deux minutes, et l'application est refaite.

METTRE À JOUR
-------------
ATTENTION : sur Mac, glisser le nouveau dossier sur l'ancien le REMPLACE et supprime vos documents.
Faites plutôt, programme fermé : double-cliquez sur le nouveau .zip, puis dans le Terminal tapez
« ditto » suivi d'un espace, glissez le NOUVEAU dossier dans la fenêtre, tapez un espace, glissez l'ANCIEN
dossier, puis appuyez sur Entrée. Relancez ensuite « Ouvrir le Modernisateur ».

DÉSINSTALLER
------------
Fermez le programme (bouton « Quitter le programme »), puis supprimez le dossier.
Attention : les PDF déposés et les documents produits, enregistrés dans ce dossier, sont supprimés avec lui.

EN CAS DE PROBLÈME
------------------
- La préparation s'arrête : lisez le message, puis relancez (elle reprend sans rien perdre).
- Le programme ne s'ouvre pas : le détail est dans le fichier programme/modernisateur.log.
